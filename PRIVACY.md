# Element Web on TOS privacy policy

The NAS administrator hosts this copy of the Element Web client. The NAS can record browser network addresses and requests for client files. Element stores session state and encryption material in the browser. The browser exchanges account details, room membership, messages and media with the selected Matrix homeserver and may use configured identity, integration or calling services. The upstream defaults include matrix.org and Element-operated services. Other homeservers involved in a federated room and participating clients may also retain data.

The homeserver operator controls account data, room history and retention. Contact the homeserver operator with requests about that data. The NAS administrator controls server access records. Session and key management is available in the Matrix account and browser. Back up encryption keys before removing browser data.

Installing and updating fetch packages and container images from the respective registries. Report packaging issues through this repository without including room content, credentials or keys.
